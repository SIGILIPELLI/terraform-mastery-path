A structured, module-wise HashiCorp Terraform training program that takes you
from "what is Infrastructure as Code" to designing a full platform's Terraform
architecture — with worked HCL examples in every module and a hands-on
capstone at the end of each level.

## How the program is organized

| Level | Focus | Modules |
|-------|-------|---------|
| [Level 1 · Entry](level-1/index.md) | Terraform & HCL foundations | 10 topics + 1 capstone |
| [Level 2 · Intermediate](level-2/index.md) | Modules, state, workspaces | 9 topics + 1 capstone |
| [Level 3 · Advanced](level-3/index.md) | State at scale, testing, environments | 9 topics + 1 capstone |
| [Level 4 · Master](level-4/index.md) | Platform architecture & operations | 9 topics + 1 capstone |

## How to use this site

- Work through each level in order — later modules assume earlier ones.
- Every topic page has worked HCL (HashiCorp Configuration Language) examples
  reasoned through against documented Terraform behavior — copy them into a
  local `.tf` file to explore, and double-check against your target provider's
  docs before running against real infrastructure.
- Each level ends with a capstone that combines everything learned in that level.
- Use the search bar (top of the page) to jump straight to a topic.

Start here → [Level 1 · Entry](level-1/index.md)
